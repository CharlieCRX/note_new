## macro64(0)

`macro64(0)` 的展开过程可以可视化为一棵二叉树（只展开最外层）：

```c
macro64(0)
  ├── macro32(0)
  │     ├── macro16(0)
  │     │     ├── macro8(0)
  │     │     │     ├── macro4(0)
  │     │     │     │     ├── macro2(0)

  │     │     │     │     └── macro2(2)
  │     │     │     │           ├── macro(2)
  │     │     │     │           └── macro(3)
  │     │     │     └── macro4(4)
  │     │     │           ├── macro2(4)
```

## 从高到低编码字符串

针对字符串：

```text
??????? ????? ????? ??? ????? 00101 11
```

`macro64(0)`最终展开为：

```C
macro(0); macro(1); macro(2); ...; macro(63); 
```

`macro(0)` 对应字符串第 0 个字符，也就是模式最左侧、高位侧的字符。`macro64(0)`展开后的宏定义，即为将字符串从左到右扫描。

每遇到一个非空格字符 0/1/?：

key  左移一位：
- c == '1' → 新位写 1
- c == '0' 或 '?' → 新位写 0

mask 左移一位：
- c == '0' 或 '1' → 新位写 1，表示该位需要匹配
- c == '?' → 新位写 0，表示该位忽略

最终`key`和`mask`的协作关系为：

- `key`按原模式的高位→低位顺序生成，其中固定`1`为 1，固定`0`和`?`为 0；

- `mask` 决定“看不看这一位”：`1` 表示必须比较，`0` 表示忽略；`key` 决定“如果要比较，这一位应该是 0 还是 1”。

`shift` 每遇到 ：

- `?` ：+1
-  `0/1` ：清零

因此扫描结束后的 `shift` = 最低位端连续 `?` 的数量。

这样最终：

- `key` = `0b 00101 11`
- `mask` = `0b 11111 11`
- `shift` = 0

然后

```C
((s->isa.inst >> shift) & mask) == key
```

代入：

```text
inst = 0x00000297
shift = 0
mask = 0x7f
key = 0x17
```

得到：

```
(0x00000297 & 0x7f) == 0x17

0x17 == 0x17
→ 匹配成功
```

## 总结

推荐以后给笔记加一个固定栏目：

```
## 我的理解 / 人话解释
```

里面不允许写源码原话，只能写你自己的话。

比如：

```
pattern_decode

源码层：
pattern → key/mask/shift

我的理解：
pattern 是“出题规则”
mask 决定哪些位要检查
key 是这些被检查位的标准答案
shift 是把最低端连续不检查的位直接裁掉
```

这个栏目非常重要。

因为如果你只能复制术语，却说不出“人话”，通常说明还没真正内化。
