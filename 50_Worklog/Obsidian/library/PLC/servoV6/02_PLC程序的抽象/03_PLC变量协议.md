经变量表、结构体定义和 PLC 主程序交叉核对，可以把当前协议确定为：

- Modbus 从站地址：`01`
- M 区：线圈，地址直接使用 M 编号，读 `01`，单写 `05`，批量写 `0F`
- D 区：保持寄存器，地址直接使用 D 编号，读 `03`，单字写 `06`，多字写 `10`
- `INT`：16 位有符号整数，1 个 D 寄存器
- `REAL`：IEEE-754 单精度，2 个 D 寄存器，低字在前
- `DINT`：32 位有符号整数，2 个 D 寄存器，低字在前
- M 区 BOOL 单项占 1 个线圈，不占 D 字
- 表中 RW/R 分别表示上位机可读写/只读

其中“单位”无法从 PLC 工程确定为固定的 mm 或 °。协议应使用：

- 位置、距离：轴工程单位 `EU`
- 速度：`EU/s`
- 超差阈值：`EU`
- 具体轴采用 mm、° 或脉冲折算值，由轴配置决定

触发型命令建议统一采用：


即使某些命令由 PLC 自复位，上位机也应有超时后主动写 OFF 的兜底逻辑。

## 四、状态值定义

### 运动状态

| 值   | 语义                           |
| ---- | ------------------------------ |
| 0    | 轴控入口未使能                 |
| 1    | 轴控入口使能、当前无点动或定位 |
| 2    | 正向点动                       |
| 3    | 反向点动                       |
| 4    | 绝对定位                       |
| 5    | 相对定位                       |

注意：PLC 源码使用的是“使能轴控”判断状态0/1，因此状态1不能严格证明伺服电机已经上使能。

### 限位状态

| 值   | 语义         |
| ---- | ------------ |
| 0    | 未限位       |
| 1    | 正向软件限位 |
| 2    | 负向软件限位 |
| 3    | 正向硬件限位 |
| 4    | 负向硬件限位 |

达到对应方向限位后，PLC 会停止定位并撤销相应方向的点动。

### 告警码

| 位       | 掩码     | 语义                           |
| -------- | -------- | ------------------------------ |
| bit0     | `0x0001` | 设备急停                       |
| bit1     | `0x0002` | 目标联动组相同职责位置已被占用 |
| bit2     | `0x0004` | 联动加入时位置超差             |
| bit3     | `0x0008` | 联动成员配置错误               |
| bit4     | `0x0010` | 联动运行超差                   |
| bit5     | `0x0020` | 轴功能块/伺服/轴指令错误       |
| bit6     | `0x0040` | 点动心跳超时                   |
| bit7～15 | —        | 当前未定义，保留               |

`设备急停解除`只解除急停锁存，不清除 bit0。需要再执行相应轴的“告警码置零”。

## 五、32位数据字序

PLC 使用两个连续 D 寄存器保存 REAL/DINT，顺序为：

```
低16位字在低地址
高16位字在高地址
寄存器内部仍按 Modbus 高字节在前
```

例如读取绝对位置得到：

```
D64 = 0x6666
D65 = 0x41CE
```

组合时应交换两个16位字：

```
原寄存器顺序：66 66 41 CE
IEEE-754顺序：41 CE 66 66
结果：约 25.8
```

不是把每个寄存器内部的两个字节再次交换。

通用解码：

```
u32 = (D[base + 1] << 16) | D[base]
REAL = reinterpret_as_float32(u32)
DINT = reinterpret_as_int32(u32)
```

写 REAL/DINT 时反向拆分：

```
D[base]     = u32 & 0xFFFF
D[base + 1] = u32 >> 16
```

建议使用功能码 `0x10` 一次写完两个寄存器，避免只更新半个32位值。

## 六、联动结构体布局

### 联动成员信息

每项4个 D 字：

```
base(i) = D1260 + 4*i，i=0..9
```

| 偏移             | 字段     | 类型 | 说明                            |
| ---------------- | -------- | ---- | ------------------------------- |
| `base+0.bit0`    | 使能     | BOOL | 1=申请/保持加入联动             |
| `base+1`         | 联动轴号 | INT  | 只能使用13、14、15              |
| `base+2..base+3` | 是否主动 | DINT | 1=主动轴，-1=从动轴，其他值非法 |

示例：将物理轴0作为联动轴13的主动轴：

```
D1260 = 0x0001  // bit0使能
D1261 = 0x000D  // 13
D1262 = 0x0001  // DINT低字
D1263 = 0x0000  // DINT高字
```

作为从动轴：

```
D1262 = 0xFFFF
D1263 = 0xFFFF
```

建议用功能码 `0x10` 一次写4个寄存器。若单独修改 `D1260.bit0`，必须保留该寄存器其他位；可以读改写，或在设备支持时使用 Mask Write Register `0x16`。

配置失败时 PLC 会把该成员的使能、联动轴号和职责清零，并设置相应告警位。

### 联动轴信息

每项4个 D 字：

```
base(g) = D1300 + 4*g，g=0..2
联动轴号 = 13 + g
```

| 偏移          | 字段       | 类型 | 说明                      |
| ------------- | ---------- | ---- | ------------------------- |
| `base+0`      | 主动轴     | INT  | 0～9；15表示无效          |
| `base+1`      | 从动轴     | INT  | 0～9；15表示无效          |
| `base+2.bit0` | 联动轴有效 | BOOL | 主动轴、从动轴均有效时为1 |
| `base+3`      | 保留/对齐  | WORD | 不使用                    |

## 七、需要修正或确认的 PLC 问题

1. “报警解除触发”当前不可用
   在主程序中，报警解除沿触发、`轴Reset := TRUE` 和自复位逻辑被 `(* ... *)` 整段注释。协议可以保留 M112～M127，但必须标记为“未实现”，或恢复 PLC 逻辑后再开放给上位机。

2. “设备急停”只是软件急停
   它通过 PLC 程序清除运动命令，不应作为符合安全等级的硬接线急停替代品。

3. 联动轴号必须限制为13～15
   PLC 直接执行：

   ```
   绝对联动轴号 := 联动轴号 - 13
   ```

   当前代码片段没有看到写入前完整范围保护。上位机写入其他值可能导致数组越界或不可预期行为。

4. “职责”暂未被 PLC 使用
   D1244～D1259 已分配并保持，但当前主程序没有发现它参与控制判定。其枚举值需要由 PLC 和上位软件另行形成正式约定。

5. 绝对定位/相对定位没有独立 Done 寄存器
   当前协议只能通过运动状态退出4/5、当前位置以及告警码组合判断完成。若需要可靠事务式控制，建议后续增加命令序号、Busy、Done、Error 和 ErrorCode。
