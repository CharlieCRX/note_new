# 一、PLC抽象的轴资源

PLC 提供的资源应理解为：

| PLC 索引 | 类型              | 工程单位 | 用途         |
| ------ | --------------- | ---- | ---------- |
| 0–9    | 线性实体轴 L0–L9     | mm   | X1、X2、Y、Z等 |
| 10–12  | 旋转实体轴 L10–L12   | °    | R、俯仰等      |
| 13–15  | 龙门逻辑轴 SYN0–SYN2 | mm   | X逻辑轴       |
|        |                 |      |            |

所以“现场电机编号”和“PLC 索引”必须分开。

例如电机10完全可以映射到 PLC 索引11，不能默认认为电机10就是 PLC 轴10。

## 推荐映射

### A组

| 现场电机   | PLC轴      | 上位机角色    | 单位  | 模式     |
| ------ | --------- | -------- | --- | ------ |
| 1      | L0 / 0    | X1 龙门基准侧 | mm  | SYN0成员 |
| 2      | L1 / 1    | X2 龙门跟随侧 | mm  | SYN0成员 |
| 3      | L2 / 2    | Y 水平左右   | mm  | 单轴     |
| 4      | L3 / 3    | Z 垂直上下   | mm  | 单轴     |
| 5      | L10 / 10  | R 旋转     | °   | 单轴     |
| 无（虚拟轴） | SYN0 / 13 | X 龙门逻辑轴  | mm  | 联动轴    |

### B组建议

| 现场电机 | PLC轴     | 上位机角色    | 单位 | 模式     |
| -------- | --------- | ------------- | ---- | -------- |
| 6        | L4 / 4    | X1 龙门基准侧 | mm   | SYN1成员 |
| 7        | L5 / 5    | X2 龙门跟随侧 | mm   | SYN1成员 |
| 8        | L6 / 6    | Y 水平左右    | mm   | 单轴     |
| 9        | L7 / 7    | Z 垂直上下    | mm   | 单轴     |
| 10       | L11 / 11  | R 旋转        | °    | 单轴     |
| 无       | SYN1 / 14 | X 龙门逻辑轴  | mm   | 联动轴   |

这样还保留：

- L8、L9：两个备用线性轴；
- L12：一个备用旋转轴，可用于俯仰；
- SYN2：一个备用联动轴。

如果实际 EtherCAT 扫描顺序已经固定，也可以使用其他索引，关键是写进设备绑定配置。

# 二、联动“配置”和联动“打开/关闭”

这正是当前 PLC 逻辑容易混淆的地方。

## 1. 联动拓扑配置

表达的是长期关系：

```
A组 X逻辑轴 = SYN0
X1 = L0
X2 = L1
X1角色 = +1
X2角色 = -1
超差阈值 = 5 mm
```

这是设备结构，通常在首次调试时确定，不应该由普通操作员每天修改。

## 2. 联动运行状态

表达的是当前是否执行电子齿轮：

```
Configured + Decoupled
Configured + Coupled
Coupling
Decoupling
Fault
```

正常运行时，用户只需要“建立联动”和“解除联动”，不需要重新选择 X1、X2 和 SYN0。

# 三、推荐的配置和开关

## 持久配置

```
联动配置[0].成员1
联动配置[0].成员2
联动配置[0].成员1方向
联动配置[0].成员2方向
联动配置[0].超差阈值
联动配置[0].配置有效
```

## 运行命令

```
联动建立请求[0]
联动解除请求[0]
```

## 状态反馈

```
联动状态[0]
0 未配置
1 已配置但未联动
2 联动建立中
3 已联动
4 解除中
5 故障
```

这样解除联动后，成员配置仍然保留，下次只需要发送“建立联动请求”，不需要重新写结构体。

这是长期更干净的设计。
