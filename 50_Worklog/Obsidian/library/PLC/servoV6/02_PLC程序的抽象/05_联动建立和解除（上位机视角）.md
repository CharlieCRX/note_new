把操作定义为“建立联动”和“解除联动”，不要叫“启动联动”。因为建立联动只是切换轴的控制权，并不会让设备开始运动。

核心体验是：

```
解除联动状态：用户控制 X1、X2 两个实体轴
建立联动状态：用户只控制 X 龙门逻辑轴
```

## 一、AxisTopology负责什么

`AxisTopology`只回答两个问题：

1. A/B组有哪些角色轴；
2. 每个角色对应哪个PLC轴下标。

例如从当前配置解析得到：

| 分组  | 角色  | PLC下标 | 实际轴  |
| --- | --- | ----- | ---- |
| A   | X1  | 0     | L0   |
| A   | X2  | 1     | L1   |
| A   | X   | 13    | SYN0 |
| B   | X1  | 4     | L4   |
| B   | X2  | 5     | L5   |
| B   | X   | 14    | SYN1 |

因此上位机不需要知道 `SYN0`、`L0` 等PLC工程名称，只需要知道：

```
A_X1 → PlcAxisIndex 0
A_X2 → PlcAxisIndex 1
A_X  → PlcAxisIndex 13
```

然后根据当前联动运行状态，决定展示哪个控制面板。

`AxisTopology`不保存当前是否已经联动，也不能通过修改 `HmiVisible` 来切换联动状态。

## 二、静态展示与动态展示要分开

`HmiVisible`表示这个轴是否允许出现在上位机中，是静态配置。

联动状态决定当前展示哪种控制方式，是动态逻辑。

例如A组X1和X2应配置为：

```
A_X1.HmiVisible = TRUE
A_X2.HmiVisible = TRUE
A_X.HmiVisible  = TRUE
```

但界面不需要同时展示三个可操作面板，而是根据状态动态选择：

| 联动状态   | X逻辑轴控制 | X1单轴控制 | X2单轴控制 |
| ---------- | ----------- | ---------- | ---------- |
| 未配置     | 禁用        | 禁用       | 禁用       |
| 已解除联动 | 隐藏或只读  | 展示       | 展示       |
| 建立联动中 | 禁用        | 禁用       | 禁用       |
| 已建立联动 | 展示        | 隐藏或只读 | 隐藏或只读 |
| 解除联动中 | 禁用        | 禁用       | 禁用       |
| 联动故障   | 禁用        | 禁用       | 禁用       |

推荐保留X1/X2的只读状态入口。即使已联动，维护人员仍然可以查看两个实体轴的位置、驱动报警和龙门偏差，但不能独立控制。

## 三、解除A组X龙门联动

### 用户看到的界面

A组处于联动状态时，主界面展示：

```
A组
┌──────────────────────┐
│ X 龙门逻辑轴          │
│ 当前位置：120.00 mm   │
│ 龙门偏差：0.08 mm     │
│ 状态：已联动          │
│                      │
│ [点动-] [点动+]       │
│ [定位] [停止]         │
│                      │
│ [解除联动]            │
└──────────────────────┘
```

此时：

- 所有X方向运动命令发给 `A_X`；
- 通过 `AxisTopology`解析到PLC下标13；
- 上位机不能向 `A_X1`和`A_X2`发送独立运动命令。

### 用户操作过程

1. 用户先停止A组X轴运动。
2. 确认逻辑X轴处于静止状态。
3. 点击“解除联动”。
4. 弹出确认提示：

```
解除A组X龙门联动后，X1和X2将变成两个独立轴。

独立操作可能造成龙门两侧位置偏差，仅允许调试或维护人员使用。

[取消] [确认解除]
```

1. 用户确认后，界面进入“解除联动中”。
2. 解除过程中，X、X1、X2全部禁止运动。
3. 解除成功后，界面切换为两个单轴控制面板。

### 解除成功后的界面

```
A组X：已解除联动

┌─────────────────┐  ┌─────────────────┐
│ A_X1 龙门基准侧  │  │ A_X2 龙门跟随侧  │
│ 位置：120.04 mm  │  │ 位置：119.96 mm  │
│ 状态：已停止      │  │ 状态：已停止      │
│                 │  │                 │
│ [点动-] [点动+]  │  │ [点动-] [点动+]  │
└─────────────────┘  └─────────────────┘

龙门偏差：0.08 mm
允许建立联动：是

[建立联动]
```

此时上位机通过 `AxisTopology`解析：

```
A_X1 → PlcAxisIndex 0 → 使用轴数组下标0
A_X2 → PlcAxisIndex 1 → 使用轴数组下标1
```

用户点动 `A_X1`时，上位机只操作下标0；点动 `A_X2`时只操作下标1。

## 四、解除后的单轴操作限制

X1、X2独立控制存在机械扭斜风险，因此建议：

- 只允许维护或调试权限解除联动；
- 独立点动使用较低的限速；
- 点动使用按住运行、松开停止的方式；
- 界面始终显示X1、X2位置和龙门偏差；
- 偏差接近限制值时给出黄色警告；
- 超过允许值时禁止继续向扩大偏差的方向运动；
- 不建议在解除联动状态下提供普通生产定位功能；
- 不允许X1和X2同时接收来源不同的自动运动命令。

解除联动的主要用途应是调试、对齐、检修，而不是正常生产运行。

## 五、重新建立A组X龙门联动

### 建立前的界面

用户在X1/X2独立控制界面完成对齐后，点击“建立联动”。

按钮附近应展示建立条件：

```
A组X龙门联动

X1位置：120.04 mm
X2位置：119.96 mm
龙门偏差：0.08 mm
允许偏差：5.00 mm

X1已使能：是
X2已使能：是
X1已停止：是
X2已停止：是
轴故障：无

[建立联动]
```

上位机不需要让用户重新选择：

```
主轴=SYN0
成员1=L0
成员2=L1
```

这些关系已经由 `AxisTopology.Group[0]`唯一确定。

### 用户操作过程

1. 用户停止X1和X2。
2. 确认两个实体轴均无故障。
3. 查看龙门偏差是否在允许范围内。
4. 点击“建立联动”。
5. 确认提示：

```
即将建立A组X龙门联动。

建立后，A_X1和A_X2将由A_X逻辑轴统一控制，
不能再独立点动。

[取消] [确认建立]
```

1. 上位机进入“建立联动中”。
2. 建立过程中禁止X、X1、X2所有运动命令。
3. 建立成功后隐藏X1/X2单轴控制面板，展示A_X逻辑轴控制面板。

### 建立成功后的控制对象

```
A_X → PlcAxisIndex 13
```

之后用户对A组X方向进行：

- 点动；
- 绝对定位；
- 相对定位；
- 停止；
- 回零或置零；

都只操作逻辑角色 `A_X`，即PLC数组下标13。

上位机不能为了实现联动同时向下标0和1发送两个定位命令。X1/X2的同步关系由PLC联动核心负责。

## 六、偏差过大时如何操作

如果X1和X2已经解除联动，并被分别移动到差异很大的位置，用户点击“建立联动”时应被拒绝。

界面提示：

```
A组X龙门联动建立失败

当前龙门偏差：8.35 mm
允许建立偏差：5.00 mm

请使用A_X1和A_X2低速点动，使两侧位置差进入允许范围，
停止两个轴后重新建立联动。
```

建议在界面提供方向提示：

```
A_X1比A_X2超前8.35 mm
建议：A_X1负向点动，或A_X2正向点动
```

这里显示的偏差应该是经过方向归一化后的机械偏差，不应直接显示两个电机原始坐标之差。

## 七、B组操作完全相同

上位机使用同一套界面逻辑，只是组号不同。

### B组解除后

```
B_X1 → AxisTopology.Group[1].Role[0] → PLC下标4
B_X2 → AxisTopology.Group[1].Role[1] → PLC下标5
```

界面展示 `B_X1`和`B_X2`两个单轴控制面板。

### B组建立后

```
B_X → AxisTopology.Group[1].Role[5] → PLC下标14
```

界面只展示 `B_X`逻辑轴控制面板。

## 八、上位机的操作对象

上位机对联动的操作对象应该是“组”，而不是三个轴分别操作。

推荐提供：

```
建立A组X龙门联动
解除A组X龙门联动

建立B组X龙门联动
解除B组X龙门联动
```

不应向普通用户提供：

```
把L0加入SYN0
把L1加入SYN0
选择主动成员
选择跟随成员
设置联动轴号
```

这些属于设备拓扑配置，不属于日常运行操作。

## 九、建议的完整界面状态

| 状态 | 界面标题   | 用户可执行操作        |
| ---- | ---------- | --------------------- |
| 0    | 未配置     | 查看配置错误          |
| 1    | 已解除联动 | 控制X1、X2；建立联动  |
| 2    | 建立联动中 | 只能等待或紧急停止    |
| 3    | 已联动     | 控制X逻辑轴；解除联动 |
| 4    | 解除联动中 | 只能等待或紧急停止    |
| 5    | 联动故障   | 查看故障、停止、复位  |

必须遵守一个原则：

> 只有明确确认“已解除联动”后，才能开放X1/X2独立控制。

如果建立或解除过程中发生通信中断、超时或部分成功，上位机不能擅自假设已经解除，也不能立即展示可操作的X1/X2面板。此时应进入“联动状态未知/联动故障”，保持三个轴的运动控制禁用，等待PLC给出确定状态。

最终用户视角可以概括为：

```
解除联动：
停止X → 点击解除 → 等待完成 → 展示并控制X1/X2

建立联动：
对齐X1/X2 → 停止两轴 → 点击建立 → 等待完成 → 展示并控制X
```

`AxisTopology`负责找到这些角色对应的PLC轴下标，联动运行状态负责决定当前哪个角色拥有控制权。
