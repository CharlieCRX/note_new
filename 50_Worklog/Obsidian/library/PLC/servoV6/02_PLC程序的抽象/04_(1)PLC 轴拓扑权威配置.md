# PLC 轴拓扑权威配置

## 1. 文档目的

本文档定义 A、B 两组设备中，上位机角色轴、现场电机和 PLC 轴资源之间的权威关联关系。

该配置由 PLC 保存并作为统一数据来源。上位机启动后读取配置，通过“组号 + 角色号”取得 PLC 轴下标，再访问对应的单轴控制参数和状态数组。

本文档只描述轴拓扑、轴属性和上位机展示配置，不描述龙门联动的建立、解除和运行状态机。

## 2. PLC 支持的数据类型

当前 PLC 变量和结构体可使用以下基础数据类型：

|数据类型|说明|
|---|---|
|`BOOL`|布尔类型|
|`INT`|单字整数类型|
|`DINT`|双字整数类型|
|`REAL`|实数类型|
|`STRING`|字符串类型|
|`IP`|IP 地址类型|
|`BYTE`|字节类型|

因此，本配置不使用 `UINT`、`UDINT`、`USINT`、`WORD` 或 `DWORD`。

轴下标、电机号、组号、错误码和结构版本使用 `INT`；配置标识、修订号和校验值使用 `DINT`。

## 3. 固定分组和角色

### 3.1 分组编码

|分组|编码|
|---|---|
|A 组|0|
|B 组|1|

### 3.2 角色编码

每组固定包含 6 个角色。角色数组下标就是角色编码。

|`Role` 下标|上位机角色|单位|
|---|---|---|
|0|X1 龙门基准侧|mm|
|1|X2 龙门跟随侧|mm|
|2|Y 水平左右|mm|
|3|Z 垂直上下|mm|
|4|R 旋转|°|
|5|X 龙门逻辑轴|mm|

角色由二元组 `(GroupIndex, RoleIndex)` 唯一确定，例如：

 (0, 0) = A组X1  
 (1, 2) = B组Y  
 (1, 5) = B组X龙门逻辑轴

## 4. PLC 轴资源约定

PLC 轴下标同时隐含了轴资源类型和工程单位：

|PLC 下标|PLC 轴名|轴类型|工程单位|
|---|---|---|---|
|0～9|L0～L9|线性实体轴|mm|
|10～12|C0～C2|旋转实体轴|°|
|13～15|SYN0～SYN2|虚拟线性轴|mm|

PLC 轴下标和现场电机号是两个不同概念。所有控制数组和状态数组都使用 `PlcAxisIndex` 作为下标，不能直接使用 `MotorNo`。

## 5. 枚举定义

### 5.1 AxisClass

|枚举名称|值|说明|
|---|---|---|
|`AXIS_CLASS_LINEAR`|0|线性实体轴|
|`AXIS_CLASS_ROTARY`|1|旋转实体轴|
|`AXIS_CLASS_VIRTUAL`|2|虚拟逻辑轴|

### 5.2 UnitType

|枚举名称|值|说明|
|---|---|---|
|`UNIT_MM`|0|毫米|
|`UNIT_DEGREE`|1|角度|

### 5.3 MotionMode

|枚举名称|值|说明|
|---|---|---|
|`MOTION_UNUSED`|0|未使用|
|`MOTION_GANTRY_BASE`|1|X1 龙门基准成员|
|`MOTION_GANTRY_FOLLOW`|2|X2 龙门跟随成员|
|`MOTION_LINEAR_SINGLE`|3|线性单轴|
|`MOTION_ROTARY_SINGLE`|4|旋转单轴|
|`MOTION_GANTRY_LOGICAL`|5|龙门逻辑轴|

## 6. 权威配置结构

### 6.1 ST_RoleAxisBinding

该结构描述一个上位机角色所绑定的 PLC 轴。

|序号|成员变量名|数据类型|说明|
|---|---|---|---|
|1|`Valid`|`BOOL`|当前角色是否绑定了有效 PLC 轴|
|2|`HmiVisible`|`BOOL`|`TRUE` 时上位机展示该角色轴|
|3|`PlcAxisIndex`|`INT`|PLC 统一轴下标，范围为 0～15|
|4|`MotorNo`|`INT`|现场电机号；0 表示无实体电机|
|5|`AxisClass`|`AxisClass`|线性实体、旋转实体或虚轴|
|6|`UnitType`|`UnitType`|mm 或 degree|
|7|`MotionMode`|`MotionMode`|轴在本组中的运动模式|
|8|`Reserved`|`INT`|预留字段|

结构示意：

 TYPE ST_RoleAxisBinding :  
 STRUCT  
     Valid           : BOOL;  
     HmiVisible      : BOOL;  
     PlcAxisIndex    : INT;  
     MotorNo         : INT;  
     AxisClass       : AxisClass;  
     UnitType        : UnitType;  
     MotionMode      : MotionMode;  
     Reserved        : INT;  
 END_STRUCT  
 END_TYPE

字段规则：

 Valid = FALSE 时：  
 PlcAxisIndex = -1  
 MotorNo      = 0  
 MotionMode   = MOTION_UNUSED

`HmiVisible` 只控制静态展示，不控制轴是否参与 PLC 内部逻辑。隐藏的 X1/X2 仍可参与龙门联动、故障处理和超差检测。

### 6.2 ST_GroupAxisMap

该结构描述一个完整的 A 组或 B 组。

|序号|成员变量名|数据类型|说明|
|---|---|---|---|
|1|`Valid`|`BOOL`|整个组配置是否有效|
|2|`HmiVisible`|`BOOL`|是否在上位机展示整个组|
|3|`GroupCode`|`INT`|0=A 组，1=B 组|
|4|`Reserved`|`INT`|预留字段|
|5|`Role`|`ST_RoleAxisBinding[6]`|本组的 6 个固定角色|

结构示意：

 TYPE ST_GroupAxisMap :  
 STRUCT  
     Valid           : BOOL;  
     HmiVisible      : BOOL;  
     GroupCode       : INT;  
     Reserved        : INT;  
     Role            : ARRAY[0..5] OF ST_RoleAxisBinding;  
 END_STRUCT  
 END_TYPE

在 PLC 配置界面中，`Role` 的类型应设置为：

 ST_RoleAxisBinding[6]

不能设置为 `[8]`，因为每组只有 6 个角色。

### 6.3 ST_AxisTopology

该结构是完整的轴拓扑权威配置。

|序号|成员变量名|数据类型|说明|
|---|---|---|---|
|1|`Magic`|`DINT`|配置魔数，用于判断是否已经初始化|
|2|`SchemaVersion`|`INT`|配置结构版本|
|3|`Reserved`|`INT`|预留字段|
|4|`Revision`|`DINT`|配置修订号|
|5|`Group`|`ST_GroupAxisMap[2]`|A、B 两个组|
|6|`ConfigCRC`|`DINT`|配置校验值；未启用校验时为 0|
|7|`ConfigValid`|`BOOL`|PLC 校验得到的配置有效状态|
|8|`ConfigErrorCode`|`INT`|PLC 校验得到的配置错误码|

结构示意：

 TYPE ST_AxisTopology :  
 STRUCT  
     Magic           : DINT;  
     SchemaVersion   : INT;  
     Reserved        : INT;  
     Revision        : DINT;  
     Group           : ARRAY[0..1] OF ST_GroupAxisMap;  
     ConfigCRC       : DINT;  
     ConfigValid     : BOOL;  
     ConfigErrorCode : INT;  
 END_STRUCT  
 END_TYPE

正式配置变量：

 AxisTopology : ST_AxisTopology;

其中：

 AxisTopology.Group[0] = A组  
 AxisTopology.Group[1] = B组

`Magic` 和 `ConfigCRC` 必须使用 `DINT`，不能使用 `REAL`。配置标识和校验值需要精确整数比较，而 `REAL` 不适合作为精确的 32 位标识值。

## 9. 上位机展示规则

一个角色轴最终是否展示，应同时判断组配置和角色配置：

FinalVisible =  
    Group.Valid  
    AND Group.HmiVisible  
    AND Role.Valid  
    AND Role.HmiVisible

PLC 逻辑示意：

GroupVisible :=  
    AxisTopology.Group[GroupIndex].Valid  
    AND AxisTopology.Group[GroupIndex].HmiVisible;  
  
RoleVisible :=  
    AxisTopology.Group[GroupIndex].Role[RoleIndex].Valid  
    AND AxisTopology.Group[GroupIndex].Role[RoleIndex].HmiVisible;  
  
FinalVisible := GroupVisible AND RoleVisible;

需要区分以下三个概念：

|字段或状态|含义|
|---|---|
|`Valid`|角色和 PLC 轴绑定是否存在、是否有效|
|`HmiVisible`|上位机是否展示该角色轴|
|运行期命令许可|当前是否允许定位、点动、回零等操作|

`HmiVisible=TRUE` 不代表当前一定允许控制；轴故障、未使能或被龙门接管时，上位机仍应展示该轴及其状态，但 PLC 可以拒绝运动命令。

## 10. 上位机访问轴信息

上位机首先根据组号和角色号读取 `PlcAxisIndex`：

GroupIndex = 1  
RoleIndex  = 2  
  
AxisTopology.Group[1].Role[2].PlcAxisIndex = 6

因此 B 组 Y 轴对应 PLC 轴 L6，所有轴数组均使用下标 6。

例如点动正转数组的基础地址为 `M80`：

点动正转[6] = M80 + 6 = M86

例如手动速度数组的基础地址为 `D0`，一个 `REAL` 占用两个 D 寄存器：

手动速度[6] = D0 + 6 × 2 = D12

通用换算规则：

BOOL变量地址 = BOOL基础地址 + PlcAxisIndex  
REAL变量地址 = REAL基础地址 + PlcAxisIndex × 2  
INT变量地址  = INT基础地址  + PlcAxisIndex

Modbus 通信协议还必须固定：

- 地址采用 0 基址还是 40001/00001 表示法；
    
- `REAL` 两个寄存器的高低字顺序；
    
- PLC 内部 M、D 地址与 Modbus 线圈、保持寄存器地址的对应关系。
    

## 11. 初始化和持久化

将 `AxisTopology` 放在 PLC 掉电保持区域（`D1400`）。

初始常量建议为：

TOPOLOGY_MAGIC          = 20260806    // DINT  
TOPOLOGY_SCHEMA_VERSION = 1           // INT

上电初始化逻辑：

IF AxisTopology.Magic <> 20260806  
   OR AxisTopology.SchemaVersion <> 1 THEN  
  
    // 装载A、B组默认配置  
    // 执行完整配置校验  
    // 校验成功后更新Magic、版本和Revision  
END_IF;

不能每次上电都无条件装载默认值，否则现场修改后的轴绑定会被覆盖。

`Revision` 在每次成功应用新配置后递增。上位机发现修订号变化时，应重新读取完整拓扑。

`ConfigValid` 和 `ConfigErrorCode` 由 PLC 校验程序写入，上位机只读，不得直接修改。

第一阶段如果尚未实现 CRC，可以保留：

ConfigCRC = 0

待配置读写流程稳定后再增加 CRC 或简单校验和，不能使用 `REAL` 保存校验值。

## 12. PLC 配置校验规则

PLC 接受或启用配置前，至少需要检查：

1. `Magic` 和 `SchemaVersion` 正确。
    
2. `Group[0].GroupCode = 0`，`Group[1].GroupCode = 1`。
    
3. 每个有效组包含 6 个角色。
    
4. X1、X2、Y、Z 的 `PlcAxisIndex` 在 0～9 范围内。
    
5. R 的 `PlcAxisIndex` 在 10～12 范围内。
    
6. X 逻辑轴的 `PlcAxisIndex` 在 13～15 范围内。
    
7. 所有有效角色的 PLC 轴下标不能重复。
    
8. 所有实体电机号不能重复。
    
9. 虚轴的 `MotorNo` 必须为 0。
    
10. X1、X2、Y、Z、X 的单位必须为 `UNIT_MM`。
    
11. R 的单位必须为 `UNIT_DEGREE`。
    
12. `AxisClass`、`UnitType` 和 `MotionMode` 必须与角色及 PLC 轴范围一致。
    

配置校验失败时：

ConfigValid     = FALSE  
ConfigErrorCode = 对应错误码

PLC 不得部分接受配置，也不得允许相关轴进入龙门联动。

## 13. 与后续龙门联动配置的关系

`AxisTopology` 是角色到 PLC 轴号的唯一权威来源。后续龙门联动参数只保存方向、比例、超差阈值和超时时间，不再重复保存成员轴号和虚轴轴号。

例如 A 组联动状态机通过角色表解析轴号：

A_X1_Axis := AxisTopology.Group[0].Role[0].PlcAxisIndex;  
A_X2_Axis := AxisTopology.Group[0].Role[1].PlcAxisIndex;  
A_X_Axis  := AxisTopology.Group[0].Role[5].PlcAxisIndex;

整体数据关系为：

A/B组 + 上位机角色  
        ↓  
AxisTopology唯一角色映射  
        ↓  
PLC轴下标0～15  
        ↓  
单轴控制数组、状态数组、龙门联动控制
