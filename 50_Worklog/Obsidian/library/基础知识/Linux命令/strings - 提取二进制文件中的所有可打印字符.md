**查看指定的 C++ 动态链接库（`libstdc++.so.6`）所支持的最高的 10 个 `GLIBCXX` 兼容版本号**。

```bash
strings /home/crx/ssd2351/tool/toolchain/aarch64-unknown-linux-gcc-12.4.0-glibc-2.37-gnu/aarch64-unknown-linux-gnu/sysroot/usr/lib/libstdc++.so.6 | grep GLIBCXX | sort -V | tail -10
```

这个命令分为四步的详细拆解：

1. **`strings /home/.../libstdc++.so.6`**
   - **作用：** `strings` 命令用于提取二进制文件中的所有可打印字符（纯文本字符串）。
   - **对象：** 这里提取的是你指定的 AArch64（ARM64）交叉编译工具链下的 `libstdc++.so.6`（C++ 标准库文件）。
2. **`| grep GLIBCXX`**
   - **作用：** 管道符 `|` 将前面提取出的海量字符串传递给 `grep` 命令。`grep` 会过滤出所有包含 `GLIBCXX` 字样的行。
   - **原因：** GNU C++ 库的 ABI（应用程序二进制接口）版本标记通常是以 `GLIBCXX_` 开头的（例如 `GLIBCXX_3.4.29`）。
3. **`| sort -V`**
   - **作用：** 对上一步过滤出的版本号列表进行排序。
   - **细节：** `-V` 参数非常关键，代表 **Version sort（版本号排序）**。它可以按数字大小逻辑正确地排序版本号（例如它知道 `3.4.10` 大于 `3.4.9`，如果用普通的字母排序，`10` 反而被排在 `9` 前面）。
4. **`| tail -10`**
   - **作用：** 截取并只显示排序结果的**最后 10 行**。
   - **结果：** 因为前面是从小到大排序的，所以最后 10 行就是这个库文件所能支持的**最高**的 10 个 C++ ABI 版本。

> **总结：** 结确认你的 **ARM64 交叉编译工具链**里的 C++ 标准库最高支持到哪个版本。
>
> 需要确保目标开发板（或者运行环境）上的 `libstdc++.so.6` 至少也支持程序编译时所依赖的那个 `GLIBCXX` 版本。
