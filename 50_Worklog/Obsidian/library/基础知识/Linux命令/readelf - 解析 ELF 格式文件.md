**核心概念**：ELF 是 Linux 下可执行文件和动态库的二进制格式，本质上记录了平台架构、依赖库、符号版本、入口信息等。

**作用**：拿到陌生 `.so` 后，先用 ELF 信息判断它能不能在目标系统上运行。

### 📖 常用参数解析

你可以通过指定不同的参数来查看 ELF 文件的不同部分。常用参数如下：

| 参数 | 作用 | 适用场景 |
| :--- | :--- | :--- |
| **`-a` / `--all`** | 显示所有信息 | 快速获取文件的**全部**概要信息。 |
| **`-h` / `--file-header`** | 显示**文件头**信息 | 查看文件类型、机器架构、入口地址等。 |
| **`-l` / `--program-headers`** | 显示**程序头**（段）信息 | 了解程序在内存中的布局，对动态链接器有用。 |
| **`-S` / `--section-headers`** | 显示**节区头**信息 | 查看文件包含的所有节区（如 `.text`, `.data`）的名称、大小等。 |
| **`-s` / `--symbols`** | 显示**符号表** | 查看文件中所有符号（函数、变量），分析导出/导入的符号。 |
| **`--dyn-syms`** | 仅显示**动态符号表** | 查看动态库对外导出的符号，比 `-s` 更聚焦。 |
| **`-r` / `--relocs`** | 显示**重定位**信息 | 分析代码中需要修正的地址引用，对理解链接过程有帮助。 |
| **`-d` / `--dynamic`** | 显示**动态节区**信息 | **最重要的选项之一**，查看共享库依赖、`SONAME`、`RPATH` 等。 |

### 🛠️ 常用命令示例

假设你有一个名为 `libexample.so` 的动态库文件，可以使用以下命令查看：

*   **查看动态库依赖**：`readelf -d libexample.so | grep NEEDED`
    这会列出该库依赖的其他共享库，即运行时必须加载哪些 `.so`。`-d` 是查看动态节区，`grep NEEDED` 则从中过滤出依赖信息。

    > 如果把一个动态库（`.so`）比作一件待售的**商品**，`readelf -d` 查看的就是这个商品的**“产品说明书/配料表”**。
    >
    > 这个“说明书”不包含商品的具体内容（即不包含函数的二进制代码），而是包含了**运行时必须遵守的规则和依赖**，具体包括：
    >
    > - **`NEEDED`**：依赖哪些其他的库（配料表）。
    > - **`SONAME`**：该库的正式版本名字（商品条形码/标准名称）。
    > - **`RPATH` / `RUNPATH`**：运行时去哪个目录找依赖库（指定超市货架位置）。
    > - **`INIT` / `FINI`**：加载时和卸载时自动执行的构造函数/析构函数地址（自动化启动/清理脚本）。
    >
    > 操作系统里的“动态链接器”（`ld-linux.so`）看不懂高级语言，它只认 ELF 结构。当程序启动时，链接器会先找到这个 `.so` 文件，打开它的 **Dynamic Section（`-d` 的内容）**，根据 `NEEDED` 去加载其他依赖库，根据 `RPATH` 去指定路径查找，最后根据 `INIT` 执行初始化代码。
    
*   **查看动态库的 `SONAME`**：`readelf -d libexample.so | grep SONAME`
    `SONAME` 是库的“大名”，对理解库的版本管理很重要。

*   **查看动态库导出的符号**：`readelf --dyn-syms libexample.so`
    这个命令会列出库对外公开的所有函数和变量名，对检查符号是否按预期导出非常有用。

*   **查看完整的动态节区信息**：`readelf -d libexample.so`
    这个命令会显示完整的动态段信息，除了依赖和`SONAME`，还可能包括`RPATH`、`RUNPATH`等信息。

*   **查看文件头确认文件类型**：`readelf -h libexample.so`
    可以确认该文件确实是一个共享对象（`DYN (Shared object file)`）。

*   **查看所有信息**：`readelf -a libexample.so`
    这会输出所有信息，输出量很大，通常需要结合 `grep` 或 `less` 来查看。

### 💡 使用小贴士

- `readelf -h` 看架构，例如 `AArch64` 表示 64 位 ARM。
- `readelf -d` 看动态依赖，即运行时必须加载哪些 `.so`。
- `readelf -V` 看符号版本，例如 `GLIBCXX_3.4.30`。
- ELF 可以理解为二进制程序和运行环境之间的“契约书”。
