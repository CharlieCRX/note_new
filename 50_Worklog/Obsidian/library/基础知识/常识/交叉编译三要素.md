**核心概念**：交叉编译时必须同时明确“为谁编、谁来编、去哪找库”。

三要素：

```
--host      目标运行平台
CC          交叉编译器
--sysroot   目标系统根目录
```

示例：

```
./configure \
  --host=aarch64-unknown-linux-gnu \
  CC=/path/to/aarch64-unknown-linux-gnu-12.4.0-gcc \
  CFLAGS="--sysroot=/path/to/sysroot -O3 -mcpu=cortex-a53" \
  --prefix=/usr
```

笔记要点：

- `--host=aarch64...`：告诉 configure 产物要跑在 ARM64 上。
- `CC=...gcc`：指定真正的交叉编译器。
- `--sysroot=...`：告诉编译器去哪里找 ARM 头文件和库。
- `--prefix=/usr`：决定安装后在目标系统中的逻辑路径。
- 如果 `CC` 写错，configure 可能找不到编译器，或者误用宿主机 gcc。
