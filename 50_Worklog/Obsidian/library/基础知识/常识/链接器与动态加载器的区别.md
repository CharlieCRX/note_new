**核心概念**：编译时和运行时找库是两套机制。

对比：

|阶段|负责者|找库方式|典型变量|
|---|---|---|---|
|编译/链接时|`ld`|`-L`、sysroot|`LIBRARY_PATH`|
|运行时|`ld-linux.so`|`/lib`、`/usr/lib`、`LD_LIBRARY_PATH`、`rpath`|`LD_LIBRARY_PATH`|

常见现象：

```
编译成功，但目标板运行时报 libfftw3f.so.3 not found
```

原因：

```
链接器编译时找到了库；
但目标板运行时加载器没有找到库。
```

解决方式：

```
export LD_LIBRARY_PATH=/path/to/libs:$LD_LIBRARY_PATH
```

或把库安装到目标板标准路径：

```
/usr/lib
/lib
```

笔记要点：

- `-L` 只影响编译链接阶段。
- `LD_LIBRARY_PATH` 只影响运行阶段。
- 编译机上的 sysroot 不会自动出现在目标板上。
- 依赖库必须真实存在于目标板文件系统中。
