## 2. 总体结论

当前驱动器被配置为：

- **PA4 = 3：位置/速度混合控制模式**；
- **PA14 = 3：位置侧采用内部位置寄存器控制**；
- **PA22 = 5：速度侧采用 IO 端子点动控制**；
- **PA62 = 5：多圈绝对值编码器模式**；
- **P4-0 = 0：内部位置使用绝对式位置指令**；
- **P3-30 = 2：物理 DI 与虚拟 DI 同时参与控制**。

需要特别区分：

1. `P3-0～P3-3` 对应 CN1 上真实存在的 `DI1～DI4`；
2. `P3-38～P3-45` 是虚拟输入功能定义，不对应 CN1 实体针脚；
3. 虚拟输入的开关状态由 `P3-31` 的 Bit0～Bit7 控制。

## 3. PA 参数配置说明

| 参数 | 写入值 | 功能 | 当前作用 |
|---|---:|---|---|
| PA53 | 0 | 伺服强制使能选择 | 使能由外部 DI 的 `SON` 信号控制，不采用软件强制使能 |
| PA4 | 3 | 控制方式选择 | 位置/速度混合模式，通过 `CMODE` 切换位置和速度模式 |
| PA11 | 0 | 电子齿轮分子选择 | 可通过 `GEAR1/GEAR2` 选择不同电子齿轮分子；当前未配置对应输入 |
| PA12 | `MOTOR_PULSE_ONEC/16` | 电子齿轮第一分子 | 实际值取决于宏 `MOTOR_PULSE_ONEC` |
| PA13 | `SERVO_PLUSE_ONEC/16` | 电子齿轮分母 | 实际值取决于宏 `SERVO_PLUSE_ONEC` |
| PA14 | 3 | 位置指令输入方式 | 使用内部位置控制，不使用普通外部脉冲定位 |
| PA21 | 10 | 点动速度 | JOG 正反向点动速度为约 10 r/min |
| PA22 | 5 | 速度指令来源 | 使用 IO 端子控制正向/反向点动 |
| PA62 | 5 | 编码器选择 | 多圈绝对值编码器 |
| P4-0 | 0 | 内部位置指令控制模式 | 绝对式内部位置指令，适用于 PA62=5 |

### 3.1 PA4 与 CMODE 的关系

当 `PA4 = 3` 时：

| CMODE 状态 | 当前控制方式 |
|---|---|
| OFF / 0 | 位置控制模式 |
| ON / 1 | 速度控制模式 |

当前 `CMODE` 被配置在虚拟输入 `P3-39` 中，由 `P3-31 Bit1` 控制。

## 4. CN1 物理数字输入端子

P100S 的 CN1 为 DB44 控制接口。物理数字输入共 4 路，即 `DI1～DI4`。

当前代码没有设置 `P3-0～P3-3`，所以下表按照手册出厂值分析。现场应读取驱动器实际参数再次确认。

| 输入 | CN1 针脚 | 功能参数 | 推定功能 | 接线用途 |
|---|---:|---|---|---|
| DI1 | 20 | P3-0，出厂值 1 | `SON` 伺服使能 | 接 PLC 或控制器的伺服使能输出 |
| DI2 | 4 | P3-1，出厂值 2 | `ARST` 报警清除 | 接报警复位按钮或 PLC 复位输出 |
| DI3 | 19 | P3-2，出厂值 3 | `CCWL` 正转驱动禁止 | 接一个方向的机械限位开关 |
| DI4 | 3 | P3-3，出厂值 4 | `CWL` 反转驱动禁止 | 接另一个方向的机械限位开关 |
| COM | 16 | 公共端 | 数字输入公共端 | 根据共阳或共阴接法连接 24V 或 0V |

### 4.1 DI1：伺服使能

由于：

```text
PA53 = 0
```

所以伺服使能必须由 `SON` 输入控制。

- SON 无效：电机不通电流，伺服不能运行；
- SON 有效：伺服使能，电机进入通电控制状态。

### 4.2 DI2：报警清除

`ARST` 一般采用瞬时脉冲控制：

```text
OFF -> ON
```

上升沿到来时，驱动器尝试清除允许复位的报警。

不建议长期保持 ARST 有效。

### 4.3 DI3、DI4：方向限位

`CCWL` 和 `CWL` 用于机械行程保护，但其功能还受到以下参数影响：

- `PA20`：是否启用方向禁止输入；
- `PA83`：触发限位后的禁止方式。

`PA83` 的典型含义：

| PA83 | 限位触发后的处理方式 |
|---:|---|
| 0 | 对应方向转矩限制为 0 |
| 1 | 禁止对应方向的指令脉冲输入 |

现场必须低速验证：

- 触发一个限位后，只禁止继续向限位方向运行；
- 应允许电机反方向退出限位区。

## 5. 虚拟输入配置

### 5.1 P3-30 = 2 的含义

`P3-30` 用于选择输入来源：

| P3-30 | 输入来源 |
|---:|---|
| 0 | 只使用 CN1 的 DI1～DI4 |
| 1 | 只使用虚拟输入 P3-38～P3-45 |
| 2 | 同时使用 DI1～DI4 和虚拟输入 P3-38～P3-45 |

当前写入：

```cpp
m_p100scfgs.append(qMakePair(MotorRegs::P3_30, 2));
```

因此系统同时保留：

- CN1 物理输入；
- 通讯寄存器控制的虚拟输入。

### 5.2 P3-38～P3-42 的实际功能

| 功能定义参数 | 写入值 | 对应状态位 | 功能符号 | 功能说明 |
|---|---:|---|---|---|
| P3-38 | 28 | P3-31 Bit0 | `CTRG` | 内部位置命令触发 |
| P3-39 | 16 | P3-31 Bit1 | `CMODE` | 位置/速度混合模式切换 |
| P3-40 | 22 | P3-31 Bit2 | `JOGP` | 正向点动 |
| P3-41 | 23 | P3-31 Bit3 | `JOGN` | 反向点动 |
| P3-42 | 27 | P3-31 Bit4 | `HOLD` | 内部位置命令停止 |
| P3-43 | 未设置 | P3-31 Bit5 | 取决于原参数 | 当前代码未定义 |
| P3-44 | 未设置 | P3-31 Bit6 | 取决于原参数 | 当前代码未定义 |
| P3-45 | 未设置 | P3-31 Bit7 | 取决于原参数 | 当前代码未定义 |

### 5.3 P3-31 位定义

```text
Bit0 = CTRG
Bit1 = CMODE
Bit2 = JOGP
Bit3 = JOGN
Bit4 = HOLD
Bit5 = 未配置
Bit6 = 未配置
Bit7 = 未配置
```

注意：`P3-38～P3-42` 只是定义每个位代表什么功能，真正让功能生效的是修改 `P3-31` 中对应的位。

## 6. 虚拟输入控制逻辑

### 6.1 CTRG：内部位置触发

```cpp
P3_38 = 28;
```

定义值 28 表示 `CTRG`。

内部位置段选好后，需要给 CTRG 一个上升沿：

```text
0 -> 1
```

才能触发一次内部位置运动。

因此软件操作建议为：

```text
1. 清零 P3-31 Bit0
2. 选择内部位置段
3. 将 P3-31 Bit0 置 1
4. 保持短时间
5. 再将 P3-31 Bit0 清零
```

不能只把 CTRG 长期保持为 1，否则不会持续产生新的上升沿。

### 6.2 CMODE：位置/速度模式切换

```cpp
P3_39 = 16;
```

定义值 16 表示 `CMODE`。

在 `PA4 = 3` 时：

```text
P3-31 Bit1 = 0：位置模式
P3-31 Bit1 = 1：速度模式
```

### 6.3 JOGP：正向点动

```cpp
P3_40 = 22;
```

定义值 22 表示 `JOGP`。

生效条件：

```text
PA4 通过 CMODE 切换到速度模式
PA22 = 5
P3-31 Bit2 = 1
```

此时电机按照 `PA21 = 10 r/min` 正方向点动。

### 6.4 JOGN：反向点动

```cpp
P3_41 = 23;
```

定义值 23 表示 `JOGN`。

生效条件：

```text
PA4 通过 CMODE 切换到速度模式
PA22 = 5
P3-31 Bit3 = 1
```

此时电机按照 `PA21 = 10 r/min` 反方向点动。

`JOGP` 与 `JOGN` 不允许同时有效。手册规定两个信号同时接通时，点动功能无效。

### 6.5 HOLD：内部位置停止

```cpp
P3_42 = 27;
```

定义值 27 表示 `HOLD`。

内部位置运动过程中：

```text
P3-31 Bit4 = 1
```

驱动器停止当前内部位置运动。

该功能只对内部位置控制有效。

## 7. CN1 数字输出端子

当前代码配置：

```cpp
P3-20 = 5;
P3-21 = 8;
P3-22 = 0;
P3-23 = 3;
```

对应关系如下。

| 输出 | CN1 针脚 | 参数 | 当前定义 | 功能说明 |
|---|---|---|---|---|
| DO1 | 31 / 32 | P3-20 = 5 | `COIN` 定位完成 | 位置偏差小于设定范围时有效 |
| DO2 | 33 / 34 | P3-21 = 8 | `BRK` 电磁制动器 | ON 释放抱闸，OFF 执行制动 |
| DO3 | 35 / 36 | P3-22 = 0 | `NULL` 无功能 | 当前未使用 |
| DO4 | 37 / 38 | P3-23 = 3 | `ALM` 报警状态 | ON 无报警，OFF 有报警 |

### 7.1 DO1：定位完成

`P3-20 = 5` 表示 `COIN`。

在位置控制模式下：

- 位置偏差大于定位完成范围：DO1 无效；
- 位置偏差小于定位完成范围：DO1 有效。

定位完成范围主要由 `PA16` 设置。

推荐连接到 PLC 的“定位完成”数字输入。

### 7.2 DO2：抱闸输出

`P3-21 = 8` 表示 `BRK`。

逻辑为：

| BRK 状态 | 抱闸状态 |
|---|---|
| OFF | 抱闸制动 |
| ON | 抱闸释放 |

CN1 对应针脚：

```text
DO2+：33 脚
DO2-：34 脚
```

#### 抱闸接线要求

DO 输出最大允许电流较小，不能直接驱动电机制动器线圈。

推荐接法：

```text
伺服 DO2
   |
   v
中间继电器或制动驱动模块
   |
   v
外部 24V 抱闸电源
   |
   v
电机制动器线圈
```

继电器线圈两端应配置续流二极管或浪涌吸收措施，并确认二极管方向正确。

断电、报警或驱动器失能时，应保证抱闸自动进入制动状态。

### 7.3 DO3：无功能

`P3-22 = 0` 表示 `NULL`。

```text
DO3+：35 脚
DO3-：36 脚
```

当前可不接线，也可以预留用于后续功能扩展。

### 7.4 DO4：报警状态

`P3-23 = 3` 表示 `ALM`。

手册定义：

| ALM 输出 | 驱动器状态 |
|---|---|
| ON | 无报警 |
| OFF | 有报警 |

CN1 对应针脚：

```text
DO4+：37 脚
DO4-：38 脚
```

程序中不要简单把 `1` 理解成报警，应按照“1=无报警、0=有报警”解释。

## 10. 当前控制时序建议

### 10.1 上电与使能

```text
1. 驱动器上电
2. 检查 DO4/ALM，确认无报警
3. 确认机械限位输入正常
4. 置位 DI1/SON
5. 驱动器使能
6. DO2/BRK 输出释放抱闸
7. 等待抱闸机械释放完成
8. 才允许下发运动命令
```

### 10.2 内部位置运动

```text
1. 将 CMODE 清零，进入位置模式
2. 写入或选择内部位置段
3. 确认 HOLD 已清零
4. CTRG 产生 0 -> 1 上升沿
5. 驱动器执行内部位置运动
6. 读取 DO1/COIN 判断定位完成
7. 清零 CTRG，准备下一次触发
```

### 10.3 点动控制

```text
1. 将 CMODE 置 1，进入速度模式
2. 确认 JOGP 与 JOGN 都为 0
3. 正向点动：置位 JOGP
4. 反向点动：置位 JOGN
5. 松开点动：清除对应位
```

点动速度为：

```text
PA21 = 10 r/min
```

### 10.4 停止与失能

```text
1. 停止位置或点动命令
2. 等待电机速度接近 0
3. 抱闸进入制动状态
4. 确认抱闸已经吸合
5. 再关闭 SON，切断电机控制电流
```

具体抱闸时序还应结合驱动器抱闸延时参数和机械负载进行验证。

## 11. 软件实现建议

建议在软件中明确维护虚拟输入位掩码：

```cpp
enum VirtualDiBit {
    CTRG_BIT  = 0,
    CMODE_BIT = 1,
    JOGP_BIT  = 2,
    JOGN_BIT  = 3,
    HOLD_BIT  = 4,
};
```

设置或清除单个位时，应采用读改写，避免影响其他功能位：

```cpp
uint16_t virtualDi = readRegister(MotorRegs::P3_31);

// 设置正向点动
virtualDi |= (1u << JOGP_BIT);
virtualDi &= ~(1u << JOGN_BIT);
writeRegister(MotorRegs::P3_31, virtualDi);

// 停止点动
virtualDi &= ~(1u << JOGP_BIT);
virtualDi &= ~(1u << JOGN_BIT);
writeRegister(MotorRegs::P3_31, virtualDi);
```

CTRG 建议封装成脉冲接口：

```cpp
void triggerInternalPosition()
{
    clearVirtualDiBit(CTRG_BIT);
    writeVirtualDi();

    setVirtualDiBit(CTRG_BIT);
    writeVirtualDi();

    clearVirtualDiBit(CTRG_BIT);
    writeVirtualDi();
}
```

实际程序中应加入适当时间间隔，并确认寄存器写入已经生效。

## 12. 风险点与待确认项

### 12.1 PA53 重复写入

代码开头和结尾均执行：

```cpp
m_p100scfgs.append(qMakePair(MotorRegs::PA53, 0));
```

由于写入值相同，一般不会改变最终结果，但建议删除重复配置，避免维护人员误认为存在特殊时序要求。

### 12.2 电子齿轮比宏值未知

以下两个宏值尚未提供：

```cpp
MOTOR_PULSE_ONEC
SERVO_PLUSE_ONEC
```

因此暂时无法计算实际电子齿轮比：

```text
电子齿轮比 = PA12 / PA13
```

需要确认：

- 除以 16 后仍为整数；
- PA12、PA13 均处于驱动器允许范围；
- 最终比例与机械丝杆导程、编码器分辨率、上位机位置单位一致。

### 12.3 P3-0～P3-3 未显式配置

当前程序依赖出厂值：

```text
P3-0 = 1
P3-1 = 2
P3-2 = 3
P3-3 = 4
```

若驱动器曾被人工修改、恢复过参数或来自不同固件版本，实际功能可能不同。

建议初始化时显式写入：

```cpp
P3_0 = 1; // SON
P3_1 = 2; // ARST
P3_2 = 3; // CCWL
P3_3 = 4; // CWL
```

### 12.4 PA20、PA55、PA57、PA83 未显式配置

这些参数会影响限位和 IO 极性：

- `PA20`：是否启用方向禁止；
- `PA55`：DI 输入有效电平；
- `PA57`：DO 输出有效电平；
- `PA83`：限位触发后的禁止方式。

必须读取实际值，不能只看 P3 功能定义。

### 12.5 抱闸必须进行断电安全验证

至少验证以下场景：

- 正常使能；
- 正常失能；
- 驱动器报警；
- 控制器掉电；
- 伺服主电源掉电；
- 通讯中断；
- 垂直轴负载状态。

任何异常状态下，都应确保抱闸进入安全制动状态。

## 14. 最终端子功能汇总

### CN1 实体输入

```text
DI1，20 脚：伺服使能 SON
DI2， 4 脚：报警清除 ARST
DI3，19 脚：正转禁止 CCWL
DI4， 3 脚：反转禁止 CWL

```

### CN1 实体输出

```text
DO1，31/32 脚：定位完成 COIN
DO2，33/34 脚：电磁抱闸 BRK
DO3，35/36 脚：无功能 NULL
DO4，37/38 脚：报警状态 ALM
```

### 通讯虚拟输入

```text
P3-31 Bit0：CTRG，内部位置触发
P3-31 Bit1：CMODE，位置/速度切换
P3-31 Bit2：JOGP，正向点动
P3-31 Bit3：JOGN，反向点动
P3-31 Bit4：HOLD，内部位置停止
```

## 15. 核心判断

当前系统的控制结构可以概括为：

```text
CN1 物理端子：负责伺服使能、报警复位、正负限位和状态输出

P3-31 虚拟端子：负责位置触发、位置/速度切换、正反点动和位置停止

内部位置寄存器：负责具体目标位置与速度参数
```

因此，`P3-38 = 28` 并不是把 CN1 的第 38 脚设置为 28，而是：

```text
将虚拟输入通道 1（P3-31 Bit0）的功能定义为 CTRG 内部位置触发。
```

这与 CN1 插头上的物理第 38 脚没有直接关系。CN1 的物理 38 脚实际上是 `DO4-`。
